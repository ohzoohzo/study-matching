# 프로필·스터디 해시태그 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프로필과 스터디에 해시태그를 여러 개 달고, 목록 검색창에서 `#태그`로 찾을 수 있게 해요. 기수는 이 해시태그 가운데 하나로 나타내요.

**Architecture:** 태그를 다듬고, 검사하고, 찾는 규칙은 모두 `recruit/recruit-logic.js`에 순수 함수로 둬요. 서버(`api/_lib/recruit.js`)와 화면(`recruit/recruit.js`)은 그 함수만 불러요. 데이터는 지금 Redis 해시의 사람·스터디 JSON에 `tags` 배열을 더할 뿐이고, 마이그레이션은 하지 않아요.

**Tech Stack:** 바닐라 JS ES 모듈, Node 20 `node:test`, Vercel 서버 함수, Upstash Redis, Montage 토큰(style.css), Pretendard.

**Spec:** `docs/superpowers/specs/2026-10-19-hashtags-design.md`

## Global Constraints

- 태그는 `#` 없이 저장해요. `tags`가 없는 예전 데이터는 `[]`로 봐요.
- 한 프로필·한 스터디에 `MAX_TAGS = 10`개, 태그 하나는 `TAG_MAX_LEN = 20`자(`#` 빼고)까지예요. 모양은 `^[\p{L}\p{N}_]{1,20}$`(u)예요.
- 오류 문구는 그대로 써요.
  - "해시태그를 다시 확인해 주세요."
  - "해시태그는 10개까지 달 수 있어요."
  - "해시태그는 글자·숫자·_로 20자까지 적어 주세요."
- 규칙 계산은 `recruit-logic.js`에만 둬요. 화면에서는 태그를 다듬거나 비교하지 않아요.
- 색·간격·모서리는 Montage 토큰과 `style.css`의 별칭만 써요. 아이콘은 Material SVG만 쓰고 이모지는 쓰지 않아요.
- 375px에서 가로 스크롤이 없어야 하고, 키보드로 모든 동작을 할 수 있어야 해요. 문구는 해요체예요.
- 화면에 넣는 태그 글자는 모두 `esc()`를 거쳐요.
- `npm test`가 통과해야 커밋해요.

## Review Focus

1. **한글 입력 중 Enter**: 한글 조합 중에 누른 Enter(`e.isComposing` 또는 `keyCode 229`)로 태그가 반쪽만 들어가거나 두 번 들어가면 안 돼요. Task 4 확인 단계에 넣었어요.
2. **태그가 없는 예전 데이터**: `tags` 필드가 없는 사람·스터디가 검색, 많이 쓰는 태그, 카드, 신청 목록에서 오류를 내면 안 돼요. Task 2 테스트와 Task 5 확인 단계에 넣었어요.
3. **붙여넣기**: "#프리온보딩7기 #프론트엔드, 주말"을 붙여넣으면 태그 3개가 돼야 해요. Task 1 테스트(`parseTagInput`)에 넣었어요.
4. **카드 안 태그 버튼**: 누르면 검색만 바뀌고 상세로 넘어가면 안 돼요. 카드의 다른 곳을 누르면 지금처럼 상세로 가야 해요. Task 5 확인 단계에 넣었어요.
5. **긴 태그 10개 (375px)**: 20자 태그 10개를 달아도 폼·카드·패널이 가로로 넘치지 않고 줄이 바뀌어야 해요. Task 6 확인 단계에 넣었어요.

**Files:**

**Interfaces:**
- Consumes: Task 1의 `normalizeTag`·`tagKey`·`tagsOf`·`cleanTags`
- Produces:
  - `matchesSearch(study, people, q)`: `#` 낱말은 스터디 태그에서 일부 일치로 찾고, `#` 없는 낱말은 태그도 같이 찾아요.

- [ ] **Step 1: 실패하는 테스트 쓰기**

```js
test("해시태그 검색: #이 붙은 낱말은 스터디 태그에서 일부만 맞아도 찾아요", () => {
  const a = { ...S("s1"), id: "t1", tags: ["프리온보딩7기", "React"] };
  const b = { ...S("s2"), id: "t2", tags: ["프리온보딩17기"] };
  const c = { ...S("s3"), id: "t3" }; // 태그가 없는 예전 스터디
  const hit = (q) => [a, b, c].filter((s) => R.matchesSearch(s, seed.people, q)).map((s) => s.id);
  assert.deepEqual(hit("#프리온보딩7기"), ["t1"]);
  assert.deepEqual(hit("#7기"), ["t1", "t2"]); // 일부 일치라 17기도 나와요
  assert.deepEqual(hit("＃react"), ["t1"]);
  assert.deepEqual(hit("#"), ["t1", "t2", "t3"]); // #만 있으면 무시해요
  assert.deepEqual(hit("#7기 pandas"), ["t1"]); // 낱말은 모두 맞아야 해요
  assert.deepEqual(hit("#pandas"), []); // #이면 이름·목표는 보지 않아요
  assert.deepEqual(hit("온보딩"), ["t1", "t2"]); // #이 없으면 태그도 봐요
});
test("검색어에 태그 넣고 빼기: 칩과 카드 태그가 써요", () => {
  assert.equal(R.toggleTagInQuery("", "프리온보딩7기"), "#프리온보딩7기");
  assert.equal(R.toggleTagInQuery("pandas", "#React"), "pandas #React");
  assert.equal(R.toggleTagInQuery("pandas  #react  csv", "React"), "pandas csv");
  assert.equal(R.tagInQuery("pandas #REACT", "react"), true);
  assert.equal(R.tagInQuery("pandas #React", "Re"), false); // 넣고 빼기는 태그 전체가 같을 때만이에요
  assert.equal(R.tagInQuery("react", "react"), false); // #이 없는 낱말은 태그가 아니에요
});
test("많이 쓰는 태그: 사람과 취소되지 않은 스터디에서 세고, 많은 순·가나다순이에요", () => {
  const people = [{ id: "p1", tags: ["React", "7기"] }, { id: "p2", tags: ["react"] }, { id: "p3" }];
  const studies = [{ id: "s1", tags: ["7기", "주말"] }, { id: "s2", canceled: true, tags: ["취소된태그"] }, { id: "s3" }];
  assert.deepEqual(R.tagSuggestions(people, studies), ["7기", "React", "주말"]);
  assert.deepEqual(R.tagSuggestions(people, studies, { exclude: ["REACT"] }), ["7기", "주말"]);
  assert.deepEqual(R.tagSuggestions(people, studies, { limit: 1 }), ["7기"]);
});
```

- [ ] **Step 3: 구현**
  - `matchesSearch`:
    - 낱말이 `^[#＃]`이면 `key = tagKey(낱말)`이에요. `key`가 비면 맞은 것으로 봐요. 아니면 `tagsOf(study).some((t) => tagKey(t).includes(key))`예요.
    - 아니면 지금 `text`에 `tagsOf(study).join(" ")`을 더해 `includes`로 찾아요.
  - `tagInQuery`: 공백으로 나눈 낱말 가운데 `^[#＃]`으로 시작하고 `tagKey`가 같은 것이 있는지 봐요.
  - `toggleTagInQuery`:
    - 들어 있으면 그 낱말들을 빼고 `" "`로 다시 이어요.
    - 없으면 `trim()`한 검색어 끝에 `"#" + normalizeTag(tag)`를 붙여요. 검색어가 비어 있으면 앞에 공백을 넣지 않아요.
  - `tagSuggestions`:
    - 사람마다, 취소되지 않은 스터디마다 `cleanTags(tagsOf(x))`를 `tagKey`로 한 번씩 세요.
    - 보여 줄 모양은 처음 본 모양이에요.
    - `exclude`의 `tagKey`는 빼고, 많은 순 → `localeCompare("ko")` 순으로 정렬해 `limit`개를 줘요.
